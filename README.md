## About the Project

**Angelina OS** is an interactive portfolio that mimics a retro operating system. It features a desktop, draggable windows, a taskbar, and a start menu. Instead of a traditional scrolling page, visitors can explore sections like **About Me**, **Skills**, **Projects**, and **Contacts** — plus a **pixel editor** and **mini-games** (Tetris, Minesweeper).

This project was built to showcase my frontend skills in a fun, memorable way: complex state management, animations, and custom UI — all without heavy libraries.

---

## Features

- **Desktop UI** — draggable windows, taskbar, start menu
- **Pixel Editor** — draw and edit pixel art right in the browser
- **Mini-games** — Tetris and Minesweeper
- **Sections** — About, Skills, Projects, Contacts
- **Themes** — custom themes via CSS variables
- **Responsive** — works on desktop and mobile
- **Smooth animations** — powered by Framer Motion

## О проекте

**Angelina OS** — это интерактивное портфолио, имитирующее ретро-операционную систему. В нём есть рабочий стол, перетаскиваемые окна, панель задач и стартовое меню. Вместо традиционной прокручиваемой страницы посетители могут исследовать разделы **«Обо мне»**, **«Навыки»**, **«Проекты»** и **«Контакты»** — плюс **пиксельный редактор** и **мини-игры** (Тетрис, Сапёр).

Этот проект был создан, чтобы показать мои фронтенд-навыки в весёлой и запоминающейся форме: сложное управление состоянием, анимации и кастомный UI — и всё это без тяжёлых библиотек.

---

## Возможности

- **Десктопный UI** — перетаскиваемые окна, панель задач, стартовое меню
- **Пиксельный редактор** — рисуй и редактируй пиксель-арт прямо в браузере
- **Мини-игры** — Тетрис и Сапёр
- **Разделы** — Обо мне, Навыки, Проекты, Контакты
- **Темы** — кастомные темы через CSS-переменные
- **Адаптивность** — работает на десктопе и мобильных
- **Плавные анимации** — на базе Framer Motion
