## About the Project

**Angelina OS** is an interactive portfolio that mimics a retro operating system. It features a desktop, draggable windows, a taskbar, and a start menu. Instead of a traditional scrolling page, visitors can explore sections like **About Me**, **Skills**, **Projects**, and **Contacts** — plus a **pixel editor** and **mini-games** (Tetris, Minesweeper).

This project was built to showcase my frontend skills in a fun, memorable way: complex state management, animations, and custom UI — all without heavy libraries.

---

## Features

- **Desktop UI** — draggable windows, taskbar, start menu
- **Pixel Editor** — draw and edit pixel art right in the browser
- **Mini-games** — Tetris and Minesweeper
- **Sections** — About, Skills, Projects, Contacts
- **Themes** — custom themes via CSS variables
- **Responsive** — works on desktop and mobile
- **Smooth animations** — powered by Framer Motion
